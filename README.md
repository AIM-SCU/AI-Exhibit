# AI-Exhibit

A small collection of web-based demos and mini-games/ web-based applications showcasing AI-based Research Paper work. The repository currently contains two main projects and a menu interface that links to them.

Projects
- `Honest Hotel?` — a mini-game (see the `Honest Hotel` folder for notes and assets).
- `InspAIred` — a mini-game (see the `InspAIred` folder).
- `Main menu page` — a central menu intended to link to the deployed versions of the above projects and other such projects/ applications.

---

# Deployment (Vercel)
- Deploy each project folder individually to Vercel (or any static host). After each project is deployed, copy its public URL into the menu page code so the main menu links to the hosted demos.
- Finally, deploy the `Main menu page` so it points to the production URLs of the projects.
